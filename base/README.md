# Общая база переключений CODE44 Shift

Приложение читает эту папку прямо из GitHub — сервер не нужен:

```
https://raw.githubusercontent.com/Code44Team/Code44-Shift/main/base/index.json
```

## Файлы

| Файл | Что внутри |
|---|---|
| `index.json` | список пакетов: id пары, заголовок, файл, число правил |
| `<пара>.json` | пакет пары языков: карты клавиш обеих раскладок + правила |
| `switchbase.json` | сводные правила всех пар (старый плоский формат) |

Id пары — два кода языка по алфавиту: `en-ru`, `en-kk`, `kk-ru`.

## Карты клавиш

В пакете лежит таблица «клавиша → символ» для каждой раскладки: все клавиши
основного блока в обеих позициях Shift. Ключ — `vk | (shift << 16)`.
Благодаря этому пара работает, даже если язык не добавлен в языковую панель
Windows: приложение подгружает карту из пакета.

## Как сюда попадают правила

Кнопка «Отправить правила разработчикам» в приложении открывает заявку (issue)
с блоком JSON. Правила из заявок мы проверяем и включаем в следующую сборку
базы — обновится она сама, кнопкой «Обновить базу переключений» в настройках.

Новую пару языков тоже можно попросить заявкой.
